# 8bit-computer

A build of Ben Eater's 8-bit breadboard computer, documented with KiCad
schematics and Digital logic simulations.

Based on the designs and schematics by **Ben Eater**:

- Website: <https://eater.net/>
- Schematics: <https://eater.net/8bit/schematics>
- Full video series: <https://eater.net/8bit/>

## Layout

- `kicad/` -- KiCad project covering the whole machine (clock, registers,
  ALU, control, RAM, program counter, output), including custom footprints
  for breadboard-friendly parts.
- `digital/` -- Logic simulations built with Digital.
- `schematics/` -- Rendered schematic images, one per module.
