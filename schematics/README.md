# schematics/ - Ben Eater's original module schematics

PNG schematics downloaded from https://eater.net/8bit - one per module page.
These are the human-readable wiring reference for the Digital circuits
(../digital/) and correspond sheet-for-sheet to the KiCad project
(../kicad/).
