# crumb/ - the Crumb build

The machine in [Crumb](https://crumb.breadboard.cc/), the breadboard
simulator - the closest dress rehearsal for the real breadboards. Empty
for now; when the build exists it goes here, plus whatever tooling it
needs (the ROM images come from [../roms/](../roms/README.md), generated
by [../tools/microcode.py](../tools/microcode.py)).
