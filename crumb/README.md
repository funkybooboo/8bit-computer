# crumb/ - the Crumb build

The machine in [Crumb](https://crumb.breadboard.cc/), the breadboard
simulator - the closest dress rehearsal for the real breadboards.
Started: the clock module (`Clock.cru`, in progress).
`sync-crumb.sh` keeps the .cru files in sync with the Steam install
(pull by default; `--push` updates the game's copy - close the game
first; `--dry-run` shows what would move). The ROM images come from
[../roms/](../roms/README.md), generated by
[../tools/genroms.py](../tools/genroms.py).
