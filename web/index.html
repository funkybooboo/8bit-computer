8-BIT COMPUTER

Ben Eater's breadboard computer, with a few extra instructions, running in the browser on the same microcode the hardware runs. It comes on with empty memory and the clock ticking. Enter a program with the switches and press RESET - it is already running.

Entering a program

  1. Get the switch settings for a program. The programs live in the repo - python3 tools/compile.py programs/count.hl prints the listing, one line per byte.
  2. Flip PROG_ADDR to PROG (on the MAR).
  3. For each line of the listing: set PROG_ADDR_A and PROG_DATA, then press PROG_WRITE (on the RAM). The RAM DATA lamps show the byte at the address you set, so you can check as you go.
  4. Flip PROG_ADDR back to RUN and press RESET (on the CONTROL).

The clock lives on the CLOCK module: AUTO runs at whatever the rate knob says, MANUAL stops it and hands you STEP_PULSE - one press, one tick, and the space bar works the same. The DEC_HEX switch on the OUTPUT picks decimal or hex on the display. RESET clears the registers but never the memory, so what you entered stays entered.

The machine is Ben Eater's design; this page is a reproduction of it, built in this repo - the programs, the docs and the tools all live there.
