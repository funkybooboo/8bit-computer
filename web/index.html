8-BIT COMPUTER

Ben Eater's breadboard computer (with added opcodes) as the machine itself - its modules, lamps and switches - running in a browser. It executes the real control-ROM images, roms/control-rom1.hex and roms/control-rom2.hex - the same microcode the hardware burns - so a program behaves here exactly the way it behaves on the machine. Bring your own program (.hl, .asm or an image); the docs are in the pane below the panel.

PANEL KEY - every unmarked module, lamp and switch is the machine's own, as wired in the Digital build (PC top right, the control logic - with RESET - bottom left, the bus rail between the module columns; docs/hardware.md). Dashed elements - and the bar above and the panes below - are this app's instruments: they do not exist on the machine.

Everything below is this app's tooling - the compiler, the entry listing, the logs, the docs - none of it is on the machine.
