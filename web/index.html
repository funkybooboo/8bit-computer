8-bit computer

Ben Eater's breadboard computer (with added opcodes), simulated in the browser. It runs the real control-ROM images, roms/control-rom1.hex and roms/control-rom2.hex - the same microcode the hardware burns - so a program behaves here exactly the way it behaves on the machine.
