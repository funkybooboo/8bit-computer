8-BIT COMPUTER

Ben Eater's breadboard computer (with added opcodes) as a front panel, running in a browser. It executes the real control-ROM images, roms/control-rom1.hex and roms/control-rom2.hex - the same microcode the hardware burns - so a program behaves here exactly the way it behaves on the machine. The LEDs, switches and display follow docs/hardware.md; bring your own program (.hl, .asm or an image) and read the docs in the pane below the panel.
