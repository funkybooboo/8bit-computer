8-BIT COMPUTER

Ben Eater's breadboard computer (with a few additions), exactly as it is wired in this repo - running the same control-ROM images the hardware burns, so it behaves here the way it behaves on the bench. It powers on with empty RAM: enter a program with the switches, then let it run.

Entering a program, the way the hardware does it: PROG_ADDR (on the MAR) to PROG, set PROG_ADDR_A and PROG_DATA from a listing, PROG_WRITE (on the RAM) per byte, PROG_ADDR back to RUN, RESET. In PROG mode the RAM DATA lamps read back the addressed byte. STEP_MODE (on the CLOCK) picks the clock: AUTO runs at the U1 rate, MANUAL makes STEP_PULSE single-step - the space bar works too. RESET (on the CONTROL) clears everything but RAM. Programs and their listings are written in the repo: the program sources, the docs (the language, the instruction set, the hardware) and the tools that build the dipswitch tables.

The machine itself - circuit design, architecture, schematics - is Ben Eater's published work; this page is a reproduction of it for study. Fully static, no backend: every file it fetches is in the repo.
